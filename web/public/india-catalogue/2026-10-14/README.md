# India research catalogue snapshot — 2026-10-14

This app projection contains 2,089 source records in 36 state/UT files, 108 screened historical Commons photographs and 35 fee variants for six attractions. It is not an exhaustive or verified production attraction catalogue. All records retain REVIEW_REQUIRED status.

index.json lists state filenames and record counts. Each state JSON embeds fee variants and screened photo metadata. thumbnails/ contains provider thumbnails; per-image attribution, source, capture date, license and restrictions are in the state record. No generated photographs, unreviewed image candidates or official-site images with unverified reuse rights are bundled.

Districts are recorded only where sourced. Tamil Nadu has 334 records and coverage from all 38 district websites; other states have national-directory coverage, not comprehensive district audits. Duplicate candidates remain explicitly marked. Unknown fees and coordinates remain unknown.

Sources: Incredible India (Ministry of Tourism), Tamil Nadu district administrations, and the earlier Wikimedia Commons/Wikipedia source catalogue. Each record retains its source URL and check date. Fees retain category, scope, channel and conditions. A website check is not a guarantee of current operator prices.

quality-summary.json describes the full upstream research release, including candidate/reference counts that are intentionally excluded from this app projection. data-dictionary.md documents upstream fields. Local thumbnails have no additional edits; consult each photo's license before reuse.
